# Game-mode artwork

Generated 2026-11-08 with the built-in `image_gen` tool in generate mode,
with one call per illustration. No CLI fallback or external reference images.
Original portrait PNGs were converted to JPEG for delivery. These are concept
illustrations, not screenshots or claims of exact map geometry.

Assets live in `public/images/menu/mode-*.jpg`. Training and Live-fire Range
share the range illustration; each match mode shares its image across solo
and hosted routes. The two `/play` category cards reuse Open World and Find a
Room. Classic and the shared home panorama remain unchanged.
